# زاد المسلم — مشروع أولي قابل للنشر

تطبيق ويب عربي باتجاه RTL وتصميم أبيض وأخضر، مبني باستخدام HTML وCSS وJavaScript بدون إطار عمل أو بناء مسبق.

## المزايا الحالية
- واجهة رئيسية متجاوبة مع الجوال.
- أقسام القرآن الكريم (فتح السورة عبر Quran.com)، والأذكار، والمسبحة الإلكترونية.
- مواقيت الصلاة حسب المدينة عبر واجهة AlAdhan API.
- قائمة ورد يومي، حفظ محلي للتقدم وعدّاد التسبيح، ووضع ليلي.
- PWA مع manifest وService Worker لتخزين ملفات التطبيق الأساسية.

## مهم قبل النشر العام
هذه نسخة أولية وليست إصدارًا دينيًا نهائيًا. راجع نصوص الأذكار ومصادرها مع مختص، واستبدل أي محتوى تجريبي بنصوص موثقة. آية الصفحة الرئيسية تُعرض كمثال مختصر؛ تحقق من تشكيلها ومرجعها من مصحف موثوق قبل اعتمادها. لا تحتوي النسخة على نص المصحف كاملًا ولا على ملفات صوتية محلية.

## النشر على GitHub Pages
1. فك ضغط الملف.
2. افتح مستودع GitHub الموجود لديك.
3. ارفع محتويات المجلد إلى جذر الفرع الذي ينشر الموقع (غالبًا `main`)؛ يجب أن يكون `index.html` في الجذر.
4. من `Settings` ثم `Pages` اختر `Deploy from a branch`.
5. اختر الفرع `main` والمجلد `/ (root)` ثم `Save`.
6. انتظر اكتمال النشر وافتح رابط Pages الذي يظهر في إعدادات المستودع.
7. اختبر الرابط على الهاتف. إذا كان الموقع منشورًا داخل مسار مستودع مثل `/repo/`، حافظ على المسارات النسبية `./` كما هي.

## تحديث الموقع
عدّل الملفات ثم ارفعها إلى المستودع مع نفس أسماء الملفات. قد يحتاج Service Worker إلى تحديث رقم النسخة في `sw.js` (غيّر `zad-almoslem-v1` إلى `zad-almoslem-v2`) عند تغييرات كبيرة حتى لا تبقى نسخة قديمة مخزنة.

## خدمات خارجية
- **GitHub Pages:** استضافة ثابتة مجانية للمشروع.
- **AlAdhan API:** جلب مواقيت الصلاة والتاريخ الهجري؛ يحتاج إنترنت وقد تختلف النتائج بحسب طريقة الحساب.
- **Quran.com:** فتح صفحات السور. النص الكامل لا يُخزّن في هذه النسخة.
- **Google Fonts:** خط Cairo وAmiri؛ عند تعذر الاتصال سيُستخدم الخط البديل.
- لا توجد قاعدة بيانات أو تسجيل دخول أو لوحة تحكم في النسخة الحالية؛ التفضيلات والعداد والتقدم محفوظة محليًا في المتصفح.

## تحويله إلى Android
### خيار سهل: PWA
افتح الموقع عبر Chrome على Android ثم قائمة المتصفح واختر `Install app` أو `Add to Home screen` إذا ظهر الخيار. يلزم HTTPS، وهو متوفر عادةً عبر GitHub Pages.

### خيار APK/AAB للنشر في المتجر
استخدم Android Studio مع Bubblewrap/TWA أو Capacitor. قبل ذلك:
1. ثبّت رابط النطاق النهائي.
2. جهّز أيقونات Android بمقاسات مناسبة.
3. اختبر وضع عدم الاتصال والتنقل والروابط الخارجية على أجهزة فعلية.
4. إذا استخدمت TWA، اضبط Digital Asset Links (`/.well-known/assetlinks.json`) ووقّع التطبيق بمفتاح موثوق.
5. جهّز سياسة خصوصية واضحة إذا أضفت تحليلات أو حسابات أو أي جمع للبيانات.

## هيكل الملفات
- `index.html` — الواجهة.
- `styles.css` — التصميم والتجاوب.
- `app.js` — وظائف التطبيق.
- `manifest.webmanifest` — تعريف PWA.
- `sw.js` — التخزين المؤقت الأساسي.
- `assets/icon.svg` — أيقونة المشروع.

## خطة تطوير مقترحة
1. تثبيت اسم وهوية التطبيق.
2. إضافة نص المصحف من مصدر موثوق مع بحث وتفسير وتلاوات مرخصة.
3. مراجعة وتوثيق جميع الأذكار والأحاديث.
4. إضافة تحديد موقع اختياري لمواقيت الصلاة والقبلة مع شرح الأذونات.
5. إضافة لوحة إدارة وقاعدة بيانات إذا احتجت مزامنة المحتوى.
6. اختبار إمكانية الوصول والأداء والأمان ثم تجهيز نسخة Android.
